What if you didn't prompt an AI to build your app — but hired a whole AI company to do it?

That's the idea behind **AI Outsourcing Studio**, which I've just open-sourced. 🚀

It's an extension for Claude Code that installs a simulated software outsourcing agency into your setup. Nine specialist roles — CEO, CTO, BA, Designer, Dev, DBA, Ops, QA, and a dedicated Devil's Advocate — each running as its own AI agent with a strict lane and real accountability.

You pitch once. Then they take over:

CEO freezes scope → BA writes the user stories → Designer sets the design system → CTO picks the stack → Dev ships it in waves → QA runs a bug loop until zero defects → the app is delivered.

No pestering you with "which framework, which database, what's the deadline?" — those decisions are delegated to the role that owns them, exactly like a real team. The Devil's Advocate stress-tests every major decision before it's committed, so you don't end up with plausible-but-wrong output.

Why I built it: single-agent "build me an app" prompts give you code with no product thinking, no design contract, and no one playing skeptic. Splitting the work across roles — with debate baked in — produces something you'd actually trust.

Try it in one line:
```
npx ai-outsourcing-studio install
```
